## Переменные и свойства (Properties)
-   ```property name="..." value="..."``` (определение переиспользуемых констант в changelog) - централизованное задание типов данных, схем или префиксов таблиц
-   ```${propertyName}``` (подстановка значения переменной в атрибуты changeSet) - динамическая замена значений во время выполнения миграции
-   ```dbms property filter``` (разные значения переменных под разные диалекты СУБД) - например для PostgreSQL тип `clob` заменяется на `text`, а для Oracle на `CLOB`
-   ```системные переменные окружения``` (передача параметров миграции из внешней среды / JVM flags) - передача динамических настроек через `-DmyProperty=value` в командной строке
-   ```global vs local properties``` (область видимости переменных в master и дочерних файлах) - управление наследованием констант при иерархическом подключении changelog
