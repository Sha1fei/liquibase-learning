## Команды Liquibase CLI
-   ```update``` (применение всех невыполненных changeSet к базе данных) - основная рабочая команда миграции схемы до актуального состояния
-   ```updateSQL``` (генерация готового SQL скрипта накатываемых миграций без применения в БД) - обязательный шаг ревью перед накатом изменений администраторами БД (DBA)
-   ```status --verbose``` (просмотр списка неприменённых миграций и текущего состояния) - проверка готовности базы данных к обновлению
-   ```history``` (вывод полной истории применения всех changeSet с авторами и датами) - аудит изменений структуры базы данных
-   ```clearCheckSums``` (очистка сохранённых хешей при необходимости исправить changeSet) - обнуляет `md5sum` в таблице лога, устраняя ошибки контрольных сумм
-   ```releaseLocks``` (принудительное снятие зависшей блокировки миграций) - сбрасывает флаг в `DATABASECHANGELOGLOCK`, если процесс упал во время выполнения
-   ```validate``` (проверка синтаксиса и корректности всех подключённых changelog файлов) - запуск валидации схемы changelog без подключения к целевой БД
-   ```changelogSync``` (пометка всех changeSet как выполненных без их реального запуска) - синхронизация Liquibase с базой, схема которой уже была создана вручную
