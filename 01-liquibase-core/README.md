## Liquibase Core
-   ```DatabaseChangeLog``` (корневой контейнер для объединения наборов изменений) - главный управляющий документ, содержащий список всех `changeSet` и подключаемых файлов
-   ```changeSet``` (атомарная единица миграции базы данных) - блок изменений с уникальной парой `id` и `author`; выполняется как единая транзакция
-   ```id / author``` (уникальный составной идентификатор миграции) - атрибуты `changeSet`; повторное применение отслеживается по комбинации `id`, `author` и пути к файлу
-   ```DATABASECHANGELOG``` (служебная таблица аудита и истории миграций) - таблица в целевой БД, где Liquibase фиксирует выполненные `changeSet`, контрольные суммы (MD5Sum) и даты применения
-   ```DATABASECHANGELOGLOCK``` (механизм распределённой блокировки от параллельного запуска) - таблица с единственной строкой флага, предотвращающая одновременное выполнение миграций несколькими инстансами сервиса
-   ```md5sum (checkSum)``` (контроль неизменяемости уже выполненных миграций) - хеш содержимого `changeSet`; при изменении ранее накаченного скрипта Liquibase выбросит `ValidationFailedException`
-   ```runOnChange="true"``` (повторное выполнение миграции только при изменении её содержимого) - атрибут `changeSet`; идеально для представлений (view), хранимых процедур и функций
-   ```runAlways="true"``` (выполнение миграции при каждом запуске приложения) - атрибут `changeSet`; полезно для служебных скриптов очистки или пересчёта в dev-средах
-   ```failOnError="true"``` (остановка всего процесса миграции при ошибке в changeSet) - значение по умолчанию `true`; при `false` Liquibase запишет предупреждение и продолжит выполнение
