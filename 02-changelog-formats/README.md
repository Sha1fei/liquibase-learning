## Форматы Changelog
-   ```YAML format (.yaml / .yml)``` (декларативное и лаконичное описание миграций без избыточного синтаксиса) - наиболее популярный и читаемый формат в экосистеме Spring Boot
-   ```XML format (.xml)``` (строгая валидация структуры через XSD схемы) - классический формат Liquibase с автодополнением и валидацией тегов в IDE через `liquibase.org/xml/ns/dbchangelog`
-   ```JSON format (.json)``` (структурированное представление миграций в формате JSON) - удобен для интеграции с внешними инструментами и API
-   ```Formatted SQL (.sql)``` (использование нативного SQL с мета-комментариями Liquibase) - файл начинается с `--liquibase formatted sql`; `changeSet` задаются комментариями `--changeset author:id`
-   ```--rollback in SQL``` (описание отката для нативного SQL скрипта) - секция `--rollback DROP TABLE ...` внутри formatted SQL файла
-   ```dbms="postgresql,mysql"``` (ограничение выполнения changelog конкретными типами СУБД) - позволяет задавать диалект-специфичные скрипты для разных баз данных
