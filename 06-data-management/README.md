## Управление данными
-   ```insert``` (вставка отдельной записи в таблицу) - декларативное добавление строки через теги `column` со значениями
-   ```update``` (обновление данных существующих строк по условию) - указание новых значений колонок и условия фильтрации `where`
-   ```delete``` (удаление строк из таблицы по заданному условию) - очистка устаревших или тестовых данных
-   ```loadData (CSV/TSV)``` (массовая загрузка данных справочников из внешнего файла) - путь к файлу через `file`, маппинг колонок и типов через вложенные теги
-   ```loadUpdateData``` (вставка новых или обновление существующих строк из файла) - выполняет upsert на основе первичного ключа
-   ```sql``` (выполнение произвольного нативного SQL выражения) - вставка raw SQL для специфичных операций, процедур или миграций данных
-   ```sqlFile``` (выполнение внешнего SQL скрипта из отдельного файла) - `path="db/scripts/seed-data.sql"`; разделяет логику схемы и наполнение данными
