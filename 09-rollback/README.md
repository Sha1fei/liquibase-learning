## Откат изменений (Rollback)
-   ```rollback block``` (явное описание обратных команд для возврата БД в исходное состояние) - пользовательский блок команд внутри `changeSet`, выполняемый при откате
-   ```автоматический rollback``` (откат стандартных операций без ручного написания команд) - `createTable`, `addColumn`, `renameTable` откатываются Liquibase автоматически
-   ```empty rollback (<rollback/>)``` (пометка необратимых операций, не требующих действий при откате) - подавляет ошибку невозможности отката для осознанно необратимых changeSet
-   ```rollbackTag <tag>``` (откат базы данных до указанного тега) - CLI команда отката всех миграций, выполненных после создания тега
-   ```rollbackCount <N>``` (откат последних N применённых changeSet) - быстрая отмена заданного количества последних шагов
-   ```rollbackToDate <date>``` (откат схемы к состоянию на определённую дату и время) - отменяет изменения, применённые после указанного таймстемпа
-   ```futureRollbackSql``` (генерация SQL скрипта отката без его реального выполнения) - проверка корректности команд отката перед применением в production
