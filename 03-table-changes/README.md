## Операции с таблицами
-   ```createTable``` (создание новой таблицы в базе данных) - основной тег для создания таблицы с указанием колонок, первичных ключей и ограничений
-   ```dropTable``` (безопасное удаление таблицы из базы данных) - атрибуты `tableName`, `cascadeConstraints="true"` (для каскадного удаления зависимостей)
-   ```renameTable``` (переименование существующей таблицы) - атрибуты `oldTableName` и `newTableName`; сохраняет данные и зависимости
-   ```remarks="описание таблицы"``` (добавление комментария к таблице в схеме БД) - документирование назначения сущности непосредственно на уровне базы данных
-   ```tablespace="custom_ts"``` (размещение таблицы в конкретном табличном пространстве СУБД) - тонкая оптимизация хранения и дисковой подсистемы
