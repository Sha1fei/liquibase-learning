## Операции с колонками
-   ```addColumn``` (добавление одной или нескольких колонок в существующую таблицу) - содержит вложенные теги `column` с типами данных и ограничениями
-   ```dropColumn``` (удаление неиспользуемой колонки из таблицы) - удаляет указанную колонку; необратимо без бэкапа или предварительного сохранения данных
-   ```modifyDataType``` (изменение типа данных существующей колонки) - например увеличение длины `varchar(50)` до `varchar(255)`
-   ```renameColumn``` (переименование колонки без изменения её типа и данных) - атрибуты `tableName`, `oldColumnName`, `newColumnName`, `columnDataType`
-   ```addDefaultValue``` (установка значения по умолчанию для колонки) - `defaultValue`, `defaultValueNumeric`, `defaultValueBoolean`, `defaultValueComputed` (например `NOW()`)
-   ```dropDefaultValue``` (удаление значения по умолчанию у колонки) - колонка перестаёт автоматически заполняться при отсутствии значения в INSERT
