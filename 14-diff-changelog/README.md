## Генерация changelog и сравнение схем
-   ```generateChangeLog``` (реверс-инжиниринг существующей БД в файлы changelog) - создание базового слепка схемы при переходе существующего проекта на Liquibase
-   ```diff``` (сравнение структуры двух баз данных и вывод различий в консоль) - поиск несоответствий между dev, stage и production базами
-   ```diffChangeLog``` (автогенерация changeSet с разницей между двумя схемами) - создаёт готовый файл миграций для синхронизации целевой базы с эталонной
-   ```liquibase-maven-plugin / gradle plugin``` (автоматизация задач diff и генерации через сборщик) - запуск генерации миграций прямо из Maven / Gradle без установки CLI
-   ```сравнение JPA сущностей с БД (diff hibernate)``` (генерация миграций на основе изменений в Java классах сущностей) - автоматическое формирование changelog по обновлённым `@Entity`
